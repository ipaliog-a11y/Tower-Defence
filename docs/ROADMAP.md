# Roadmap

Owner may insert radical gameplay. Treat phases as **default**, not a contract.

## Phase 0 — Concept (done)

- Design exploration (grid/decay, 8×8, conduits)
- Paper play kit
- HTML mockup
- Pivot: 10×10, tower-attached links, winding path
- Godot 4 slice + GitHub

## Phase 1 — Playtest the slice (current)

- Keep iterating rules/UX/juice in Godot
- Log notes in `docs/PLAYTEST.md`
- Freeze a vertical-slice rule set in `docs/DECISIONS.md` when notes are “numbers,” not “rewrite power”

## Phase 2 — 2.5D board kit (after rule freeze)

Start **only** when the owner says rules are stable enough to skin, or readability still fails despite juice.

First assets (small):

- Ground / path / 2–3 scenery / Core / Base
- 4 tower silhouettes
- 5 enemy silhouettes
- Camera: Godot 3D orthographic **or** 2D isometric

Not first: every upgrade skin, campaign art, cinematic VFX.

## Phase 3 — Content pipeline

- Second map as a resource (not hardcoded only in `game_data.gd`)
- Optional in-run upgrades (2 tiers)
- Export a Windows build

## Phase 4 — Meta (explicitly later)

- Weak start (Cap I only)
- After-run currency from wins **and** fails
- Unlock Tf / Rg / Dr and modest ranks
- Do not let two upgraded Caps skip the puzzle

## Later / optional

- EMP, Grid Worms
- More maps / occasional larger boards
- Mobile layout
- Hard mode permanent wear

## Explicitly not scheduled

- Engine switch
- Multiplayer
- Full F2P monetization
